# Repository maintenance

- This is the implementation repository. Keep CloudStream reference checkouts unchanged.
- Read README.md and docs/REFERENCES.md before modifying provider behavior.
- Edit src/ and the single animeSamaBaseUrl value in config.json; providers/anime-sama.js is generated by npm run build.
- Keep native plugin and companion addon contracts distinct. Nuvio native plugins expose streams only.
- Run npm run check after code changes. Keep the bundled artifact synchronized. Use npm run test:live for extraction/transport changes when network access permits; never persist signed playback URLs or cookies.
- Preserve relative IDs, sparse array positions, website group order, selected-language gaps and Sendvid placeholder rejection.
- Do not infer Japanese audio from VOSTFR, report unknown quality as known, or introduce network-only cosmetic enrichment on playback.
- Preserve bounded host concurrency, failure isolation, per-caller cancellation, no signed-link caching and playback headers.
- Commit no credentials, private cookies, generated media or debug dumps. Sanitized verification reports and deterministic fixtures belong here.
